# Bilan ODF — application locale (orthodontie)

Application 100% locale de gestion des bilans orthodontiques.
**Aucune donnee patient** n'est presente dans ce depot : les donnees restent
uniquement en local sur chaque poste (~/BilanODF_Data). Ce depot ne sert
qu'a la distribution du code et aux mises a jour automatiques de l'application.
